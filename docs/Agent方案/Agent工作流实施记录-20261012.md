## 数据合同

|对象|存储/合同|关键字段|
|---|---|---|
|运行|`agentRuns`，`audit-agent-state/1`|sessionId、objective、requirements、workflowIds、plan、inputs、steps、questions、checkpoints、modelInputs、usage、revision、transitions、resumeOf|
|输入|运行的 inputs|稳定 id、原路径、快照路径、SHA-256、大小、来源、sourceTaskId、输入状态|
|计划|`audit-plan/1`|工具与流程/阶段、输入文件、参数与来源、依赖、实际调用、成果检查点|
|外层/内层模型输入|`agentModelInputs`，`audit-node-context/1`|最终消息、工具、请求体和端点、需求及输入引用、重建记录、预算、返回用量与截断信号；不保存认证头|
|完整工具返回|`agentToolResults`|会话、运行、调用、精确工具名、完整返回；模型中使用稳定引用与有界样本|
|受管任务|`tasks`，`audit-tool-result/1`|实际引擎与状态、参数、输入版本、幂等依据、重试关系、原始返回、成果、验证和发布状态|
|问题|运行的 questions|稳定 id、问题原文、来源、open/answered、回复原文、消息编号、补充依据|

运行从 running 转为 waiting_for_user、completed、failed、stopped 或 interrupted。待补状态可以继续；失败、停止、中断通过新的关联回合恢复。completed 不回退为执行中。已保存成果和未决状态不会因上下文压缩消失。

计划与任务中的成功，以实际步骤、已登记依赖和成果检查为准；模型的最终文字不能把失败或未结束计划变成完成。失败的阶段成果可以保留查看，不视为已经发布的有效后续输入。

## 本次测试版本的限制

自动审批拒绝了向未明确授权的外部模型转发项目资料和启用在线审计调用。本次采用仅本机模型、仅本机审计执行的已获准路径；模拟模型只提供三类体验任务，实际成果由独立程序生成。在线模型地址与允许传送的资料范围明确后，再做真实接口接入与验收。

因此，这份记录确认五项的工程实现与本机可测试结果；G04 中的企业网关/跨页 OCR 验收以及 G06 的真实远端恢复验收仍待完成。没有把离线夹具成功标为整个平台或真实企业模型已经全部验收。

旧桥接文件继续排除。既有业务规则、生产需求路由、OCR、新增 MCP、Skill 受管脚本与平台准确性评测均按用户要求保持原状。
