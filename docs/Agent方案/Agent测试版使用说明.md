# Agent 测试版使用说明

版本：0.1.0-internal.34，Windows x64。

双击程序目录中的 **启动Agent离线体验.cmd**。启动器会打开聊天程序并准备合成示例项目，无需安装 Node、Python、pnpm 或登录原审计工具箱。移动程序时须保留整个“AI助手”目录。

## 可以立即测试的操作

1. 输入“读取示例序时账，检查借贷是否平衡，生成差异清单”。示例共有 8 条分录，预期产生 1 条差异，差额 200 元。
2. 查看对话中的实际步骤，预览或打开成果 CSV、Excel 和 Parquet 文件。
3. 新建对话，输入“提取公司、凭证日期、科目名称、借方金额、贷方金额五列”。预期保留 8 条记录；预览成果时可点击带来源记录的行，回查已保存的原始资料。
4. 输入“检查项目资料结构，输出文件清单”。查看结构或资料清单。
5. 处理中点击停止，再点击“继续任务”。已完成且校验通过的成果会复用；输入变化会使相关步骤重新执行。
6. 输入离线体验不支持的目标，例如“请做预算预测”。程序会在聊天中说明需补充的任务范围，保留等待状态。可回复上述三类受支持任务，或新建对话。
7. 从“历史对话”切换任务，关闭程序后重新打开，检查执行记录与成果仍然可读。

可以添加自己的 CSV 或 Excel 项目测试前三种操作。离线示例中的借贷检查使用“公司、凭证日期、凭证编号、借方金额、贷方金额”这些实际列名；其他列名会返回真实参数或字段错误。复杂任务应连接正式模型后验证。

## 模型与执行范围

离线体验的模型是明确标注的模拟服务，仅演示借贷检查、指定列提取、资料结构检查和补充问题。文件处理由实际审计程序完成，模拟服务不构造审计成果。

完整 Agent 执行器已接入现有 63 项独立程序与 16 项通用操作。当前版本只允许 HTTP 本机模型地址（localhost、127.0.0.1、::1），并限制审计程序访问外部网络。要用已有本机兼容模型处理更多自然语言任务，直接打开“AI助手.exe”，在运行设置填写本机 API 基础地址与实际模型名；该模型需支持工具调用。

企业模型、OCR、在线查询的真实接入与验收尚未完成。自动审批拒绝了向未明确授权的外部模型传送项目资料及启用在线审计调用，因而本次交付采用本机测试路径。正式接入需要明确服务地址和可发送的资料范围。

## 数据与验证状态

离线体验的数据存放于 `%LOCALAPPDATA%\AuditAgentOfflineTest`，与普通启动的 `%LOCALAPPDATA%\AuditAssistant` 分开。启动器每次更新演示服务的临时端口，保留历史对话和成果；可再次打开启动器继续使用。

执行使用项目或附件的隔离副本，原文件不覆盖。旧成果对应原输入版本；文件完整性检查通过表示实际执行、文件格式与哈希通过，业务语义自动验收仍属于本轮未开展的 G01。成果预览只显示样本，完整结果可打开文件查看。

本轮范围为 G02、G04、G05、G06、G11 的工程实现和本机验收；G01、G03、G07–G10 保持原有状态。细节见同目录的“Agent工作流实施记录-20261012.md”和“Agent能力绑定矩阵.md”。
