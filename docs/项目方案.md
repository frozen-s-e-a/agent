# 项目方案

## 产品形态
主界面只有对话、项目、设置。对话支持独立会话和项目会话；创建项目时选择工作文件夹。工具调用、文件读取/写入、错误、重试、审批、Token 统计都以内嵌时间线卡片显示，不再设置运行过程页。删除旧功能列表、旧项目管理页和账号页；项目数量不受账号限制，但模型供应商凭据仍需在设置中配置。

## 架构
```text
Electron Shell ──版本化 framed RPC── Web Client
       └──────── Node Harness ───────┘
                         │事件
                 Python Audit Worker
                         │
                 选定项目文件夹
```

UI、Harness、审计 worker 三进程隔离。renderer 不能直接访问文件系统或 shell。Harness 负责会话循环、模型路由、工具编排；Python worker 负责 Excel/PDF/底稿计算；file-ops 负责路径、hash、原子写入；audit-domain 负责规则、证据链和报告模型；usage 负责实际 Token、估算和聚合；settings、plugin-manager、mcp、skills 各自单一职责。跨模块只依赖 contracts。

## Harness 稳定性
append-only JSONL 事件是唯一事实源，UI 和统计均为 projection。turn/step/request/tool 的开始、结束、失败、取消、重试全部落盘并带 requestId/attemptId。崩溃恢复到最后已提交边界；不自动重放非幂等写操作。每个工具有 schema 校验、参数上限、超时、取消、并发策略和 readOnly/exclusive 标记。文件写入采用临时文件、flush、同卷原子 rename、前后 hash 和备份。坏 PDF、超大表格、中文空格路径、锁定 Excel、磁盘满都转为可读错误卡片，不能闪退。

## 插件、MCP、Skill
插件 manifest 声明 id、版本、API 兼容性、权限、入口和哈希；下载、校验、安装、健康检查成功后才切换活动版本，失败自动 journal 回滚。MCP 支持 stdio 与 Streamable HTTP，工具命名为 `mcp__server__tool`，有启动/调用超时、并发上限、环境变量白名单和断线重连，默认不启用。Skill 是带 manifest、输入输出 schema、适用审计阶段和测试样例的版本化工作流包，静态校验后按项目启用。

## Token 页面
每个 assistant turn 尾部显示 Usage，点击展开：总 Token、输入、缓存读/写、输出、推理（供应商提供时）、模型路由、耗时、TTFT、tokens/s。会话底部显示 turns/steps、累计 Token、缓存命中率；未知值显示“未知”。provider 实际 usage 是账单依据，上下文压力估算只用于容量提示；重试按 attempt 记录，父子会话不重复累计。
