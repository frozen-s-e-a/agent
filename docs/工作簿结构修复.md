# 0.1.0-internal.6 工作簿结构与 Markdown

原“查看数据结构”与规则表格导入共用路径，把空白首行当作表头，后续有数据的列便触发“数据列超出表头”。Excel 结构查看现使用专门的工作簿读取路径，不猜测表头，不丢弃超出表头的业务值；结果明确标记为结构概览及有限样本。规则计算工具保留严格字段校验。

移除以解压总量 128 MiB 为界的结构预览拒绝，改用只读工作簿和有界 XML 尾部读取，不因大片格式空白建立全部单元格对象。合并范围无法完整确认时保留未知／不完整标记。

已用用户报错底稿的隔离本地副本验证：14 个工作表完成结构概览，约 3.4 秒，原件 SHA-256 未改变。未将原文件上传模型服务。另验证空白首行、合并标题、隐藏工作表和后续行额外列。

对话加入 react-markdown + GFM 排版，HTML 不执行、远程图片不自动加载，外部网页链接只在用户点击时打开。旧对话也使用新排版。
