# 需求边界与验收

|编号|要求|验收|
|---|---|---|
|R01|删除旧功能列表/项目页|导航无旧入口|
|R02|现代项目|新建项目、选择根目录、多轮对话、数量不限|
|R03|删除账号|无本地账号实体；凭据独立管理|
|R04|执行记录入对话|工具/文件/错误/Token 卡片可展开|
|R05|独立设置|模型、凭据、权限、插件、MCP、规则分栏|
|R06|稳定 Harness|worker 被杀可恢复；超时/取消/重试可见|
|R07|扩展|插件安装升级回滚；MCP；Skill 发现校验|
|R08|工程化|模块单责、契约文档、Git 检查|
|R09|隔离|src、tests、artifacts 分离；业务文件不入库|

边界：不逆向旧二进制，不迁移旧账号，不把真实底稿放入仓库；不承诺任意第三方插件直接兼容。文档、底稿和模型输出都是不可信数据，不能提升权限。删除/覆盖/越界访问/外部程序执行需要确认卡片。

阶段：P0 协议和崩溃恢复 spike；P1 UI/项目/设置；P2 Harness/工具/Token/worker；P3 审计 Skill 和报告；P4 插件/MCP 事务与 Windows x64 测试包。
