# AI 审计助手使用说明
## 单文件启动

本次提供一个可独立携带的 `AI审计助手-0.1.0-internal.29.exe`。直接双击即可，首次运行自动将完整程序释放到本机用户目录，之后复用已准备文件；不要求管理员权限或手动解压。保留现有项目与模型设置。内部的 AI助手.exe 仍由完整运行目录支持，外层单文件 EXE 已包含这些文件。


版本：`0.1.0-internal.29`，Windows x64，2026-10-10。

## 打开程序

解压后双击 `AI助手/AI助手.exe`，也可使用同目录 `启动AI助手.cmd`。整个 AI助手 文件夹都属于程序，不能只复制 EXE。程序已包含 Node、Python、63 项审计处理器和配置模板，无需安装原 SW 审计工具箱或 pnpm。

项目根目录 `启动AI助手.cmd` 和 `AI助手桌面版.lnk` 直接打开本次独立程序包；`开发启动AI助手.cmd` 构建源代码版本。

## 项目与资料

点击“新建项目”，填写名称，选择资料目录。数据源、处理配置表和底稿模板应放在该目录内，任务路径可填写项目相对路径。建议在项目中建立 input、config 和模板目录，文件夹名称可自定。

选择资料后使用推荐操作，或按 `Ctrl+K` 搜索工作。IPO 披露下载、公告下载、汇率和工商查询无需选择资料。工作记录保留执行步骤，成果文件集中展示已生成结果。

## 处理与成果

先确认资料范围，再填写处理规则。格式说明与输入框共用后台校验规则。需要配置表的操作提供“复制配置模板”；复制到项目后填写，再选择该文件执行。

月间分析需确认日期、科目及金额映射和借贷方向。毛利率分析先展示检测结果，审阅维度与映射后确认继续。明细底稿按检查数据源、检查模板、保存配置、校验、生成的顺序执行，模板批注定义字段、数据区域和分组。

成果显示预览、提示及文件。“继续处理”将成果送入下一项操作；失败时修改参数后重试。失败记录不会把其他任务的文件作为本次成果。

审计处理器的成果位于项目 `outputs/<任务编号>/`，并记录文件哈希、任务参数及阶段结果。通用资料操作也另存成果；“保存明细底稿配置”明确写入指定工作目录的 config，这是配置保存操作。表格处理不会覆盖原资料。

## 文件与配置

表格任务以 XLSX / XLSM 为主，结构分析、月间、JET、银行核对等另支持 CSV / TSV，具体以页面提示和《任务与文件格式对照》为准。不能把 XLS、XLSB、ODS 改扩展名作为 XLSX 输入。

企查查整理接受 DOCX 报告目录；图片重命名接受图片目录；PDF 提取区分文字层和扫描件。AI 提取可读取文档、表格和图片，扫描件需要视觉模型。图片支持 PNG、JPG、JPEG、WebP、BMP、TIFF。

按行列重建数据的部分表格操作输出 XLSX，并提示不保留原 VBA 和复杂版式。底稿与公式填充保留模板公式，在 Excel 打开时重算。Excel 是打开成果和重算公式的可选工具，不是任务运行的必需依赖；配置关键单元格为无缓存公式时，需先在 Excel 重算并保存。

多期账龄文件按由近及远连续编号，如 `1.2026.xlsx`、`2.2025.xlsx`、`3.2024.xlsx`。明细配置支持科目方向、正负号、数据源、分组、文本字段、查找映射、按公司生成空底稿。账龄合计不一致会显示提示并保留基础数据供复核。

## 模型与注协

在“运行设置”填写 API 地址、文本模型、视觉模型和密钥，保存后可测试连接。密钥使用系统加密保存在本机，任务参数和项目成果不保存密钥。视觉模型需支持图像输入。

注协工商查询、批量导出、子公司查询及关联方在线穿透需要有效登录。需要使用时点击“登录注协”，在官网窗口完成登录，客户端自动保存有效会话。日常登录无需手填 JSON；高级授权导入仅提供已有会话的可选导入。

本次按用户要求跳过注协在线授权验证，相关流程已用合成协议响应测试。未登录不影响其他本地任务、IPO 和公告下载、汇率查询。关联方使用已有工商资料并关闭在线穿透时可本地执行。

## 数据保存与排查

项目记录与加密凭据位于 `%LOCALAPPDATA%/AuditAssistant/`；输入与成果保存在选择的项目目录。程序包不携带用户凭据、真实底稿或研究用原程序。

双击无窗口时，确认完整解压且 resources/app/runtime 目录存在，尝试同目录启动脚本。打开“运行设置”检查版本号及“审计处理器：随程序内置”。失败时按具体错误检查列名、配置表、格式或模型设置。

验收范围及清单见《独立客户端验收与使用》和 build-manifest.json。
