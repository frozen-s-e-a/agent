# AI 审计助手测试版使用说明

版本：`0.1.0-internal.35`，Windows x64，2026-10-13。

## 单文件启动

双击 `AI审计助手-0.1.0-internal.35.exe`。不再创建“正在准备审计工作台”窗口。单文件中压缩的运行文件在首次启动或内容更新时自动释放到本机用户目录，后续校验并复用，损坏后自动修复；不需要管理员权限，也不需要另行安装 Node、Python 或原 SW 审计工具箱。需要跳过释放过程时，可直接运行已展开目录中的 `AI助手.exe`。

目录程序包也可直接双击 `AI助手.exe`。移动目录程序包时须保留整个 AI助手 文件夹。

## 开始测试

首次使用按引导配置兼容 OpenAI 接口且支持工具调用的模型服务，填写服务地址、文本模型和密钥，然后建立项目并选择资料目录。已有设置和项目会继续保留。

在聊天中描述任务目标、资料范围和成果要求。可以点击输入框附近的建议，测试资料结构检查、指定字段提取或借贷平衡检查。Agent 自动调用实际审计程序，缺少资料或关键口径时集中提问。

项目侧栏支持切换项目、新建对话、对话改名和删除。右侧面板可选择本轮资料范围，并查看成果。执行计划、实际步骤、补充问题和成果跟随每轮对话保存。停止后可继续任务。

本次 `.35` 修复取消了模型轮次和工具调用次数上限。大任务接近 128K 窗口时，程序保留完整原文、要求和结果，自动重建有界上下文并按引用分页读取；网关拒绝过大的请求时先缩减并重试，业务工具内的模型调用也支持分段读取和进度保存。被省略的必要要求未实际提供给模型前，不能直接宣布完成。执行步骤默认折叠，当前处理说明可按需展开查看。任务超时和模型窗口本身仍有效。

更新后的文件仍叫 `AI审计助手-0.1.0-internal.35.exe`。必须先退出旧程序，再重新启动更新文件。应用采用单实例锁；旧窗口未退出时，双击新版只会唤回旧进程，不会加载新代码。现有对话、项目和模型设置继续保留。

聊天发送的附件可直接供全部已登记本地审计程序处理，无需先放进项目目录。附件会生成本次任务的工作副本，计划与执行使用同一资料引用；项目里有同名文件时，以明确的附件编号区分。文件结构预览只是有限样本，完整处理由实际审计任务完成。工作表及实际表头行需要依据文件结构确认。

成果可预览或打开。预览只显示样本；支持行来源的结果可点击来源按钮，查看已保存的原始资料。聊天执行使用隔离副本，原文件不覆盖。旧成果保留与原输入版本的对应关系。

## 离线体验

如使用目录程序包，可双击同目录的 `启动Agent离线体验.cmd`，打开合成示例项目。示例模型是明确标注的本机模拟服务，文件处理仍由真实审计程序完成。

输入“读取示例序时账，检查借贷是否平衡，生成差异清单”，预期 8 条分录产生 1 条差异，差额 200 元。也可测试字段提取、来源回查、停止继续及历史恢复。离线体验仅演示这几类任务。

## 模型和验证范围

运行设置支持实际配置的模型服务地址、模型选择、连接测试和密钥保存。密钥在桌面程序中使用系统加密保存。公网服务使用 HTTPS，本机和内网地址可使用 HTTP。

独立审计程序的模型请求只能访问已配置的模型对话接口，密钥仅在运行时传递；不会因此开放外部审计查询。企业模型、OCR 和在线查询尚未完成真实接口验收。注协授权配置入口已保留，本次没有开展真实在线授权测试。

本次回归通过 75 项 Node 单元和集成测试、7 项 Python 模型传输测试、27 项通用处理测试、1 项工作簿结构测试、4 项附件测试，以及覆盖 63 项独立审计程序的 83 个合成案例。另有归档读取专项、历史失败输入重建和程序包检查。主要聊天流程使用本机模拟模型验证。

执行与文件完整性检查通过，表示实际执行状态、成果文件、格式和哈希可核查；逐任务业务语义自动验收尚未完成。

普通运行数据存放于 `%LOCALAPPDATA%\AuditAssistant`；离线体验数据存放于 `%LOCALAPPDATA%\AuditAgentOfflineTest`。当前测试包和详细记录见随包 `build-manifest.json`、`验收记录` 及 `Agent测试版使用说明.md`。
