# AI 审计助手桌面版

当前版本为 `0.1.0-internal.28`，首页已改为资料工作台。先选择项目和资料，再搜索或选择具体操作；成果可以继续处理，过程保存在工作记录。查看新版交互和预览启动方式，请阅读 [项目工作台预览说明](项目工作台预览-20261008.md)。下文九类流程说明保留用于历史记录和预置工作模板。

## 启动

在项目根目录双击 `启动AI助手.cmd`。脚本会检查 Node.js 并启动 Electron 桌面窗口；也可以运行 `node scripts/dev.mjs`。如果看到“请双击 AI助手桌面版启动应用”，说明打开的是浏览器页面，不是桌面客户端。

## 历史流程与工作模板

任务中心包含九类任务：

1. 表格与资料整理
2. 科目、账簿与凭证
3. 月间分析与测算
4. 抽凭与抽样
5. 银行业务
6. 底稿与明细表
7. 披露、附注与链接
8. 关联方与外部查询
9. 信息提取与辅助处理

任务卡按业务分组，分类按钮和搜索可筛选任务。进入任务后，左侧是阶段导航，主工作区展示输入、执行与成果。执行成功会收起参数，突出阶段结果；窄窗口也能查看成果。

## 项目与文件

点击“新建项目”，填写名称并选择包含审计资料的目录。也可以点击“体验示例项目”创建合成示例。支持选择文件和目录；工具需要本期/上期、序时账/流水、数据/模板时，分别在对应角色中选择。

内置表格工具接受 CSV、TSV、XLSX、XLSM，不支持 XLS、XLSB、ODS。PDF 提取仅读取文字层。MCP 功能会显示客户端接受的格式及原接口尚未验证的边界。每项执行均有格式和参数检查。内置处理另存成果；可能改写资料的 MCP 操作要求先选用工作副本并确认影响范围。

配置表类操作提供“准备配置模板”，将配套模板复制到项目 `input` 目录，保留已有同名文件，并记录模板哈希。请先在 Excel 中填写配置与引用资料，再执行。明细表生成需要 64 位 Excel。

## 阶段操作

- **确认资料范围**：选择资料后点“确认并继续”。直接查询类任务可以不选文件。
- **执行阶段**：指定处理内容与输入角色，预览字段，填写或选择参数，再点“执行本阶段”。月间分析提供字段映射和科目方向编辑，银行流水按文件配置账户与表头。
- **确认阶段成果**：执行成功后检查结果，再点“确认并继续”。必需前序阶段未确认时，后续不能执行。可选阶段可填写原因后跳过。
- **使用成果**：可打开成果、预览表格或查看完整工具返回。CSV、Excel、Parquet 支持有限行预览；JSON、文本和 Markdown 支持文本预览。PDF、DOCX 提供文字摘录。
- **复核与归档**：填写复核意见后生成真实的 `任务记录包.json` 和 `复核意见.md`；已归档任务只读。

任务记录保存到“处理记录”。重新打开恢复同一任务的资料、参数、阶段确认和成果。修改上游输入或参数会撤销后续确认，要求重新处理。旧版未保存的人工确认不会被虚构；已有的输入、执行结果会恢复供重新复核。

长任务在后台执行，离开页面后可以继续查看。应用关闭导致中断时显示中断状态，可检查输出后重试。MCP 返回错误会显示失败和实际原因。

## 运行设置

“运行设置”可填写服务地址、文本/视觉模型和密钥，保存时使用系统凭据加密。支持测试连接、查看模型列表，并显示 MCP、Excel 和版本信息。默认处理模式用于内置处理器的资源策略；MCP 使用自身引擎。部分 MCP 的 AI 或工商查询授权仍由对应服务配置决定。

## 真实能力边界

内置工具和 Legacy MCP 工具均通过后台白名单调用。工具没有注册、参数不完整或输入文件不符合要求时，任务会显示实际错误；客户端不会用占位结果冒充完成。外部查询、银行函证和部分底稿功能还依赖对应服务、模板、Excel 环境或本机授权，任务卡会显示当前可用能力。
