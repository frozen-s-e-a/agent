# AI助手审计工具箱 · Windows 桌面版 0.1.0-internal.6

这是按 v0.4 方案搭建的可运行内部测试程序。**尚未达到“全部原功能迁移并验收”的正式首版要求。** 原有方案与全量范围保留，不能把本测试包视为全功能替代品。

## 启动

双击桌面上的“AI助手桌面版”快捷方式，或打开测试包目录双击 `AI助手.exe`。界面在独立桌面窗口中打开，直接加载本地资源，不启动网页服务、不需要打开浏览器。包内自带 Electron、Node.js、Python 与计算依赖，不需要本机安装开发环境。可以整体移动测试包文件夹，不能只复制 exe。首次打开不需要应用账号。

本机测试使用独立数据目录；正常启动后，应用状态保存到 `%LOCALAPPDATA%\AuditAssistant`。Windows 用户之间的模型密钥不可互用。测试包没有数字签名，也没有自动更新功能。

## 一次完整操作

1. 创建项目，选择名称和资料文件夹。选择文件夹即授权该项目读取其中的文件并在 outputs 生成新结果。
2. 点击“查看数据结构”，选中文件，再点“预览首个文件与字段”。CSV 默认 UTF-8，GB18030 文件可在高级参数指定 `{"encoding":"gb18030"}`。
3. 在工具搜索中选择操作，明确填写字段、规则和处理模式。列名必须与数据一致。
4. 点击“确认并执行”，任务及结果会出现在当前对话。
5. 展开结果预览，打开 Excel、分卷 CSV 或结果文件夹复核。`manifest.json` 包含输入输出 hash、运行参数摘要和完成状态；`来源数据.parquet` 保留原始行位置。

也可点击“用合成示例体验”。该示例明确标记为合成数据，其中记002凭证借贷相差 200 元。凭证分组字段填写 `公司,凭证日期,凭证编号`，借方/贷方字段填写 `借方金额`、`贷方金额`。

## 模型与对话

1. 打开“设置 → 模型服务”，填写服务地址和密钥。支持兼容 API 的 HTTPS 地址及本机/内网 HTTP 地址；根地址遇到 404/405 时会尝试 /v1。
2. 点击“获取可用模型”，分别选择文本模型与视觉模型；也可以展开“手动填写模型名称”。模型列表不提供可靠的视觉能力标识，请按供应商说明选择。
3. 点击“测试文本连接”或“测试视觉连接”。测试使用当前填写的配置，无需先保存；发送一条短文本，最多请求 32 个输出 Token，可能产生少量用量。成功代表对话接口可用，不代表已验证图片识别能力。
4. 保存设置。密钥由 Windows 加密保护，留空保留现有密钥。401 提示检查凭据；403 提示检查模型授权、账号权限、IP 白名单和网关策略。
5. 在对话输入框右下方选择模型，每个对话独立记忆。自动模式对纯文本使用文本模型，有图片时使用视觉模型。未配置视觉模型时会要求先选择。

点击输入框左下方回形针，选择“添加文件”“添加文件夹”或“添加图片”。无需创建项目也可使用。文件夹递归收集文件，显示清单；图片显示缩略图，附件可在发送前移除。添加时只保存本地副本，**点击发送后，文本、附件摘录与图片会发送到配置的模型服务**。原文件不会修改。连接失败或停止生成后，附件保留在草稿，便于重试。

附件读取边界：

- TXT、Markdown、CSV、TSV、JSON 等文本：每文件最多 12,000 字符，UTF-8 优先，失败尝试 GB18030。
- Excel（xlsx/xlsm）：前 5 个工作表、每表前 50 行和前 40 列；公式保留为文本，不重算。
- Word（docx）：正文与表格文字，不包含嵌入图片；PDF：前 20 页文本，扫描页明确提示需要 OCR。
- PNG、JPEG、WebP、GIF：以图片输入发送，需要所选模型支持。其他格式仅提供文件信息，明确标记没有读取正文。
- 每条草稿最多 20 项、200 个文件、100 MiB；单文件 20 MiB，单图片 8 MiB，文件夹最多 12 层，不跟随内部符号链接。
- 每轮最多摘录 30 个非图片文件、48,000 字符，超出部分明确标记为未读取。当前及最近历史合计最多发送 6 张图片，较早未重发图片会在模型上下文说明。附件摘录不是完整审计核查。

支持流式回复、停止生成、对话保存、供应商用量和已发送附件记录。附件的本地副本与摘录留存在本机应用数据目录，暂未提供自动清理功能。现已接入自动工具调用，也保留命令和参数卡片入口。

本次采用隔离的本机兼容协议测试服务验证，未使用用户真实密钥或付费服务进行联调。实际服务的授权、余额与视觉支持需通过当前配置验证。费用估算、MCP/Skills 执行和插件管理尚未实现。

## 直接用对话处理文件

创建项目后直接描述需要处理的文件，或在独立对话中添加附件后发送要求。例如：“读取这份 Excel 的工作表和表头”“提取客户、余额两列并生成新文件”。模型会浏览文件、读取结构、选择工具、执行并依据实际结果答复。工具调用与输出文件显示在对话中，可展开核对和打开结果。

项目文件的输出位于项目 outputs；独立对话附件的工作副本及输出位于应用数据目录的 workspaces，任务卡提供打开入口。输入原件不覆盖。模型只可调用已实现的 16 项审计工具，不能执行任意命令或编辑未授权目录。业务口径不清楚时需要补充说明。

自动执行需要所选模型及服务支持兼容工具调用。连接测试只检查短文本请求，不能证明工具调用已开启。若提示服务不接受工具定义，请在服务端启用或换用支持该能力的模型。

每轮对话最多 8 轮模型请求、16 次工具调用，总时限 10 分钟；单个本地任务等待上限 4 分钟。点击停止可中断模型、文件预览和当前任务。工具错误会显示真实原因，并可由模型修正参数后再次执行；已发布结果仍保留。工具样本和附件摘录均不是全量核查。

设置成功、一般错误和连接测试结果在 3 秒后消失。对话执行记录和结果保留。输入区域已移除深色选中外圈。

## 两种本地模式

- 自动：根据文件大小、Excel 解压体量和预算估计，选择轻量或批量。
- 轻量本地：独立 Python 进程、内存分析连接，无持久分析数据库。
- 大批量：独立 Python 进程、落盘分析库、DuckDB 临时溢写，输出完整 Parquet 和每卷不超过 10 万行的 CSV。

本实现两种模式共用 SQL 规则，避免两套金额/空值口径。它与方案中 pandas 轻量路径存在明确实现差异，详见 implementation-notes.md。

默认单个重任务；内存监控超预算时停止进程。DuckDB 查询内存设置为进程预算的一半，临时溢写上限 2 GiB。非常大的 Excel 会被拒绝，不能把体积限制理解为旧格式已经完整兼容。当前没有缓存盘选择、分片续算和自动缓存清理。

## 文件、金额和恢复

原文件不覆盖。输出先在项目 outputs 下临时目录生成并校验，再发布到任务编号目录。失败或取消不发布成功报告。执行时输入变化会阻止发布。重试使用相同任务编号，已发布且校验通过的结果直接复用；处理中断的计算从步骤开始重做。

CSV 解析保留引号内换行；多余数据列、重复表头、无效金额会报错，不静默截断。金额支持最多 6 位小数的 Decimal(38,6)，超过精度或解析失败会拒绝。科目代码保持文本。Excel 输出中可精确表示的数值结果写为数值，长编号和不适合数值表示的内容写为文本；本工具不会计算原工作簿中的公式。

CSV 会对可能被表格软件执行的文本公式增加单引号；完整原值保留在 Parquet。超过 50,000 条结果不生成 Excel，使用分卷 CSV 和 Parquet。Excel 模板格式/公式/宏的保真迁移尚未完成。

临时目录以点开头，重试会创建新的独立临时目录。当前没有自动清理；确认任务无运行和恢复需要后，可由使用者清理所属任务的临时目录，不要删除原件或已发布结果。

## 当前不能替代旧程序的部分

银行函证与流水、抽凭抽样、明细底稿和上期结转、披露附注、链接替换、关联方穿透、外部查询下载、OCR、复杂 Office 模板、宏、原 AI/MCP/Skills 扩展，以及所有未识别参数分支，仍属首版待完成范围。

这些能力没有用占位结果或模拟按钮冒充完成。需继续建立旧程序原入口、参数、模板和输出的实际基线；第三方查询还需要用户有效的服务凭据和实际联调环境。未读取或复制旧程序 config.json、业务数据库、真实底稿、账号或密钥。


## 工作簿结构与 Markdown 更新（internal.6）

Excel“查看数据结构”生成结构概览 JSON 和 Excel／CSV 结构报告，列出所有指定工作表、隐藏状态、保存的范围、可读取的合并范围与前 11 行、前 40 列样本；每格最多 200 字符。保留原始行号，首行不自动认定为表头。大工作表使用有界读取，保存的范围可能包含格式空白，合并范围完整性见报告标记。这是结构和样本报告，不是全量业务数据导入；金额核对、筛选等工具仍需指定真实工作表和表头行。旧失败任务可在新版中点击重试。

AI 回复支持 Markdown 标题、粗体、斜体、嵌套列表、表格、引用和代码块，流式回复和历史消息均生效。点击 HTTP/HTTPS 链接时使用默认浏览器打开；不执行回复里的 HTML，不自动加载外部图片。
