# Windows 桌面版更新 · 0.1.0-internal.3

按用户要求，以 Windows 桌面应用交付。双击“AI助手桌面版”快捷方式或包内“AI助手.exe”进入独立窗口。

本次改动：

- 界面直接读取随程序分发的本地资源，不再从 localhost 网页服务加载。
- 桌面主进程与后台使用标准输入输出管道通信，不启动 HTTP 服务、不监听应用端口。
- 删除浏览器 API 调用和浏览器模式回退；界面仅接受受限桌面桥接。
- 保留原生文件夹选择、窗口最小化/最大化、任务栏、多进程计算、Windows 密钥加密。
- 后台仍可按用户模型设置调用外部模型 API；本地审计工具不需要模型连接。
- 继续使用已有本机项目和会话存储，无需搬迁业务资料。

桌面实现采用 Electron。当前版本仍为内部测试包，业务覆盖与前一轮一致；本次桌面化不代表全功能迁移已验收完成。
