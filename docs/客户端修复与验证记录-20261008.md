# 客户端修复与验证记录

日期：2026-10-08。修复版本：`0.1.0-internal.27`。

本记录对应此前《客户端核查报告》发现的问题。修复已落到客户端、后端调度、输入合同、工作流状态和测试中。79 个操作入口已全部覆盖到九类任务；这表示入口和流程映射完整，不代表 63 个外部 MCP 业务工具均已完成真实业务验收。

## 1. 实际修复

| 问题 | 修复后的行为 |
|---|---|
| 漏掉 9 个操作入口；7 组同名工具混用 | 使用内置 ID 和 `mcp_` ID 精确映射；九类任务共 43 个阶段覆盖 79 个不同入口，无悬空映射。名称区分“新增固定值列”和“合并同名列”等不同语义。 |
| 工具报错却显示成功 | 识别 MCP `isError` 和结构化失败；保存错误详情。需要补充确认的返回显示等待输入；重试仍走原引擎。 |
| 统一文本框丢失参数类型 | 表单保留整数、布尔、列表、枚举与 JSON 类型；后端独立验证。银行核对区分账簿与流水；月间分析提供字段、科目及方向配置；多份流水逐文件设置账户与表头。 |
| 格式含糊、目录难以使用 | 每个操作显示输入格式和限制；不支持的文件及时拒绝。支持资料目录授权和预览；产出文件可以作为后续输入。未验证的兼容性明确标注。 |
| 缺少配套配置文件 | 已知工具可以复制原工具箱模板到项目，保留源模板 SHA-256 标识；同名文件不会被覆盖。 |
| 阶段状态只保存在页面 | 后端持久化资料、参数、任务与阶段状态。只有真实成功结果可以确认；改动上游资料或参数会重置受影响的后续确认。可选阶段必须记录跳过原因。 |
| 历史记录恢复为空 | 恢复已保存的资料、参数和结果。旧任务按实际运行记录迁移，要求重新确认，不能凭空还原过去未保存的人工复核意见。 |
| 复核与归档只有界面效果 | 填写复核意见后生成项目内真实的 `任务记录包.json`、`复核意见.md`，归档任务只读，文件可打开。 |
| 成果不方便使用，窄窗口消失 | 成果放在主内容区，显示状态、预览、输出文件与错误详情；1100 像素窗口仍可查看。成功后折叠输入，突出结果。 |
| skill 与模型设置未接通 | 后端加载 8 个 skill，工作流提供相应业务指引；模型设置支持密钥保存、连接检查、模型列表及 MCP/Excel 环境状态。业务 skill 是指导规则，不新增独立执行引擎。 |

## 3. 验证与边界

自动化测试共 **48 项通过**：10 项单元测试、6 项既有调度/Agent 集成测试、6 项新增工作流回归测试、25 项 Python 工作器测试、1 项 Excel 布局测试。工作器测试覆盖全部 33 个 JET 规则。TypeScript 检查与 Vite 构建通过。

桌面测试共两组：

1. 在真实 Electron 中完成资料选择、结构检查、列选择、阶段确认、返回历史、继续任务、填写复核意见和生成真实归档；检查银行输入、月间映射、模型密钥入口及窄窗口成果。两项内置处理实际执行。无页面异常。
2. 逐一打开九类任务的 43 个阶段，检查 79 个不同操作的表单；复制一份实际工具箱模板到隔离测试项目。无页面异常。

真实安装的 MCP 服务使用合成资料完成 **8 项调用**：`monthly_preview`、`jet_test_inspect`、`tool_preview`、`detailed_table_inspect`、`detailed_table_inspect_template`、`detailed_table_save_config`、`address_split`、`bank_flow`。其中银行核对生成实际 Excel 成果；不是用模拟成功响应代替业务执行。执行记录由 `artifacts/repair-20261008/live-smoke-pointer.json` 指向。

尚未逐项完成其余 MCP 工具的真实业务验收，尤其需要外部服务授权、特定底稿模板、真实业务数据或 Excel 自动化的流程。接口未完整声明的格式只展示已知接受范围与待验证说明，不声称支持全部 Excel、文档或图片格式。

## 4. 启动

原来的 `AI助手桌面版.lnk` 或 `启动AI助手.cmd` 仍是启动入口。脚本使用项目自带 Node/Python，每次先构建当前源码再打开 Electron，无须手工运行 `pnpm`。设置页显示版本及构建时间。启动日志：`artifacts/logs/startup.log`。

日常状态目录保持为 `artifacts/dev-state`；上述自动化测试使用独立状态与合成资料。
