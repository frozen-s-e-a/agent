# 原版 MCP 工具迁移

助手现在通过隔离的 stdio 兼容层连接原版 `SW审计工具箱` MCP 服务：

- 工具元数据随应用发布，工具搜索中可见原版 63 个工具（银行、底稿、抽样、查询、文件、AI 等）。
- 对话模型收到 `legacy_<工具名>` 函数定义，可直接按原版参数调用。
- 服务进程以当前项目目录为工作目录；文件、配置和输出路径会校验在项目目录内。
- 原版工具调用沿用现有任务卡、执行记录和结果展示；MCP 服务异常只影响该次调用，不阻塞助手启动。
- 原版服务依赖 `SW_AUDIT_TOOLBOX_EXE` 环境变量，未设置时默认寻找桌面上的 `SW审计工具箱\sw audit tool box.exe`。

原版服务会在每个对话轮次按需启动，关闭应用或轮次结束后释放进程。API 密钥、Cookie 等参数不会从原工具箱配置文件自动复制。
