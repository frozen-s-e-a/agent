# 本地源码仓库说明

本仓库最初保存 2026-10-12 桌面开发目录的源码快照，当前已更新至 `0.1.0-internal.33`，包含聊天 Agent 的本机执行、上下文、状态、恢复与成果回查实现。仓库独立初始化，默认分支为 `main`，不配置远程地址。

## 内容与依赖

- `src/client`、`src/host`：React/TypeScript 界面、Electron 桌面入口、Node.js 后台。
- `src/audit-worker`、`src/audit-domain/runtime`、`src/audit-domain/recovered`：通用资料操作、63 项独立审计任务及业务核心源码。
- `src/resources/templates`：随程序使用的空白配置表和模板。
- `tests`、`scripts`、`docs`：现有测试、构建与打包脚本、使用及设计文档。
- `package.json`、`pnpm-lock.yaml`、`pnpm-workspace.yaml`：JavaScript 直接依赖、完整锁定文件和构建脚本权限。
- `requirements.txt`：22 项固定版本的 Python 运行依赖；`src/audit-domain/recovered/requirements-research.txt` 保留原有研究核心依赖清单。
- `dependency-lock.json`：本次核对的运行时版本及依赖版本、许可证元数据。
- `source-snapshot.json`：原开发目录文件的 SHA-256 清单和仓库整理调整，用于追溯来源。

`node_modules`、构建输出、第三方运行时安装目录、日志、模型、本地状态、密钥、桌面快捷方式和真实业务资料不纳入提交。依赖通过锁定文件安装，程序运行链路使用独立任务客户端。

按用户要求，旧桥接文件不进入仓库：排除 `src/legacy-mcp/`、旧 MCP stdio 客户端、兼容层、原程序桥接、Python 桥接执行器、旧版工具清单与盘点资源，以及仅用于旧工具箱盘点和模板迁移的脚本、旧桥接接入说明。具体范围记录在 `source-snapshot.json` 的 `excludedFromRepository` 中。工作流测试改为引用当前 `arguments.mjs` 和独立任务清单。

`.gitignore` 中构建运行时规则改为根目录 `/runtime/`，确保 `src/audit-domain/runtime` 的 Python 业务源码可以正常提交。初次快照整理只调整仓库内容与引用；后续 Agent 工程改动见 [Agent 工作流实施记录](Agent方案/Agent工作流实施记录-20261012.md)。

## 环境准备

在 Windows x64 准备 Node.js 24.19.0、pnpm 11.19.0 和 Python 3.12.14。以下命令在仓库根目录的 PowerShell 中执行；Python 安装目录替换为本机实际路径。

```powershell
pnpm install --frozen-lockfile
python -m pip install --target build/python-packages -r requirements.txt
node scripts/runtime.mjs "C:\Path\To\Python312"
$env:PYTHONPATH = (Resolve-Path build/python-packages).Path
build/python/python.exe -B scripts/verify-runtime-dependencies.py
```

`runtime.mjs` 会准备隔离的 Python 和 Node.js 构建运行时；`verify-runtime-dependencies.py` 会核对 22 项固定版本、导入常用运行库并生成打包所需的依赖许可证清单。

## 开发与验证

```powershell
pnpm typecheck
pnpm build
pnpm test
$env:PYTHONPATH = (Resolve-Path build/python-packages).Path
build/python/python.exe -B tests/integration/test_worker.py
build/python/python.exe -B tests/integration/test_layout_inspection.py
build/python/python.exe -B tests/integration/test_attachments.py
$env:PYTHONPATH = "$(Resolve-Path build/python-packages);$(Resolve-Path src/audit-domain)"
build/python/python.exe -B tests/integration/independent_tasks.py
```

执行 `pnpm dev` 或 `开发启动AI助手.cmd` 启动源码开发版本。根目录 `启动AI助手.cmd` 面向已生成的单文件程序，需要先完成打包。

执行 `pnpm package:test` 构建目录程序包。打包前需完成界面构建、运行时与依赖核对；单文件构建还需按已有交付脚本完成程序包验证和封装，不属于本次源码入库范围。
