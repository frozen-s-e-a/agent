# 项目工作台交互预览

版本：`0.1.0-internal.28`。日期：2026-10-08。

## 设计方向

围绕项目资料、操作和成果组织工作。首页提供资料列表及最近工作，不再以九个固定任务板块作为导航。独立操作在当前资料的上下文中出现，复杂工作通过可选模板启动。

布局为浅色左侧项目导航、顶部项目名称与操作搜索、主区域的资料/工作/成果。选中资料时出现适合的操作条；配置与结果占用主区域，不使用常驻右侧文件栏。颜色以白色 `#ffffff`、工作区底色 `#f6f8f8`、文字 `#253c3b`、辅助文字 `#64786d`、边线 `#e2e9e8` 和强调色 `#23655a` 为基础。中文优先使用系统雅黑 UI 字体。资料是主内容，避免把小功能铺成等大的卡片。

## 查看效果

双击项目根目录的 **`预览项目工作台.cmd`**。脚本使用自带 Node/Python，生成单独的示例项目、实际执行一次结构检查，再构建和打开桌面预览。预览状态位于 `artifacts/workbench-preview-state`；企业、金额与交易对手均为合成资料。

常规入口 `启动AI助手.cmd` 也会加载本版工作台，继续使用原来的日常状态目录。

## 可以直接体验的路径

1. 在资料列表中选中序时账，查看相关操作；点击预览查看真实表格内容。Ctrl/Shift 可增减选中的资料。
2. 点击“开始工作”，或按 Ctrl+K 搜索操作。79 个注册操作均可检索。搜索 IPO 可直接找到三个交易所的下载入口，填写日期和更新模式；本次未实际执行联网下载。
3. 从序时账开始“提取需要的列”，填入 `公司,科目编码` 并执行。
4. 对生成的 CSV 点击“继续处理”，选择“新增固定值列”，填写新列名与值后执行。两次处理保存在同一项工作中，可以切回前一步查看。
5. 返回“工作记录”恢复该工作，或从“成果文件”查看来源、打开文件、继续处理。内置成果复用前校验 manifest 中的文件哈希，重新生成当前输入来源信息；前一步资料和记录保留。
6. 搜索结果可以收藏；收藏的操作出现在左侧。月间分析、分录测试、明细底稿生成提供现有可选工作模板。

本版输入框用于搜索注册操作，尚未实现任意自然语言目标的自动规划。推荐操作根据资料名称、格式及已读取字段筛选。工作模板目前是三个预置流程，尚未提供用户自建模板和拖动步骤编排。
