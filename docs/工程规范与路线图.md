# 工程规范与路线图

目录：`src/` 源码，`tests/` 测试，`scripts/` 工具，`artifacts/test/windows-x64/` 测试包，`artifacts/release/` 发布包，`docs/` 文档。业务项目和运行数据放 `%LOCALAPPDATA%\AuditAssistant` 及用户选择目录。禁止提交 `.env`、密钥、真实底稿、缓存、node_modules、dist 和 artifacts。

建议技术栈：Electron + React/TypeScript + Node Harness + Python worker + SQLite/JSONL projection。提交格式 `feat|fix|refactor|docs|test|build(scope): subject`；主分支保持可构建；每阶段同步 ADR、schema、测试结果和回滚点。

验收门槛：`git diff --check`、类型检查、中文路径越界测试、worker 崩溃恢复、幂等性、坏文件、密钥扫描、插件安装回滚。正式发布再增加 Windows 签名、SBOM、依赖漏洞扫描。
