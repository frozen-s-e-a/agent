# 客户端功能与文件格式逐项核对（2026-10-08）

> 本表为修复前核查基线。入口映射、参数类型、格式校验和流程状态已在 `0.1.0-internal.27` 更新，详见 [客户端修复与验证记录](客户端修复与验证记录-20261008.md)；当前表单和后端共同使用 `src/workflows/contracts.mjs` 定义输入要求。

这是当前实现的事实清单，不是支持承诺。79 个注册入口不等于 79 个独立业务功能；其中有内置/MCP 同名入口和多个业务共用步骤。63 个 MCP 名称已与本机服务 tools/list 对照，未逐个执行业务。内置扩展名来自读取器源码，MCP 格式来自接口声明；“未列明”表示不能据此推定支持所有 Excel/图片格式。
