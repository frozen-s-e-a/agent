## 十万行基准

- Windows 10.0.19045 x64；Python 3.12.14；16 个逻辑处理器；物理内存约 15.6 GiB。
- 两个 UTF-8 CSV，各 50,000 行。每个完整凭证的借贷两条记录刻意分在不同文件，金额均为 0.10。
- 总计 100,000 行，核对全部 50,000 个跨文件凭证，容差 0.01，预期差异 0。
- 轻量本地：7.971 秒，100,000 行完整导入，0 条差异。
- 大批量：9.241 秒，100,000 行完整导入，0 条差异。
- 本次测试进程峰值 RSS 约 101.1 MiB。包含导入、核对、证据输出与发布；不是全系统内存，也没有模拟内存溢写压力。
- 原始记录和数据 hash 见 artifacts/test-results/benchmark.json。

此前导入基准被主动中止，原因是缺少可选 pandas/numpy 的最小运行时在逐值绑定时反复探测模块，造成明显开销。最终实现采用有界、逐值严格 SQL 转义的批次插入，并补充包含 SQL 字符的字段与内容测试。中止结果不作为通过数据。

以上仅是窄表跨文件凭证核对单场景，不代表其他工具、复杂连接、全部格式或百万/千万行容量。未做冷缓存/热缓存区分。
