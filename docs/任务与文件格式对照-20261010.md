## 逐项参数与成果示例

必填状态以客户端表单为准；可留空、已保存路径及默认值会在页面说明。成果示例来自合成资料验收，不包含客户数据。

### 合并同名列（add_column）

XLSX / XLSM；按任务字段填写配置；成果保存在项目 outputs 目录

|参数|含义|填写要求|
|---|---|---|
|file_path|文件或文件夹路径: 要处理的 Excel 文件路径或包含 Excel 文件的文件夹路径|必填|
|keyword|文件名关键词: 用于过滤文件名的关键词，留空则处理所有 Excel 文件|可选／可留空；默认 |
|column_name|待合并列名: 需要合并的列名（如：客户）|必填|
|delimiter|连接符: 用于连接多个值的分隔符（如：,或;），留空则直接拼接|可选／可留空|
|max_column_num|最大列数: 相同列名的最大数量，不足时自动插入空列|必填|

验收成果示例：duplicate.xlsx。
