# 迁移研究进度快照

这些文件从本机 `artifacts` 中整理，保存自有研究脚本、JET 参考实现、合成输入以及关键观测和验证结果。大型工具、原运行时、解包二进制和测试状态没有纳入。

- `core-logic-20261010`：JET 条件与特征研究实现、观测和验证记录。
- `core-coverage-20261010`：63 个 MCP 入口和共享核心的定位清单与采集脚本。
- `migration-analysis-20261010`：独立迁移证据及逐项功能台账。

研究用 Python 依赖与生产程序依赖不同，例如 JET 参考实现需要 pandas 和 NumPy。采集脚本中的原始本机路径、工具位置和旧模块依赖需要按复现环境调整。顶层研究快照不包含这些完整运行环境。
