# 0.1.0-internal.5 本地工具与界面更新

## 对话驱动本地处理

已接入完整流程：模型提出结构化工具调用 → 后台校验当前项目／已发送附件范围 → 本地执行 → 返回真实结果 → 模型继续分析。

模型可浏览文件、读取表格结构或文档摘录、查询已实现工具及参数、运行现有 16 项审计工具、查看历史任务结果。Excel 结构读取包含工作表名称与隐藏状态、合并范围、表头、样本值和单元格格式。项目文件直接在项目范围执行；独立对话附件使用本地工作副本，输出通过任务卡打开。原文件保持不变。

对话中显示每次工具调用的状态和实际返回内容，实际任务显示参数、结果文件、预览及错误。错误交回模型后可根据明确字段修正参数；停止生成会中止正在读取的文件或请求取消当前执行任务。发布与取消竞争时以真实任务最终状态为准。应用重开保留调用和结果记录。

每条消息最多 8 轮模型请求、16 次工具调用，总时限 10 分钟；单个自动执行任务等待上限 4 分钟。只有登记的工具可调用，不提供任意系统命令、任意路径或原文件覆盖能力。已有 16 项工具的业务边界不因此扩大，原程序全功能迁移仍待完成。

模型服务必须支持兼容的 tools/tool_calls 协议。连接成功只说明文本接口可达，不保证服务已启用工具调用。服务拒绝工具定义时会给出提示；应在服务端启用相应能力，或切换模型。应用不能替服务端开启该能力。

## 界面

输入框与模型下拉框移除深色焦点外圈，使用浅色反馈。保存成功、一般错误、模型连接和模型获取结果显示 3 秒后消失；通知浮动显示。对话历史和任务执行记录继续保留。

## 验证

隔离的本机测试服务产生工具调用，真实 Python 引擎处理合成 CSV 和 Excel。覆盖项目、附件、参数失败后纠正、停止执行、非法工具拒绝、跨目录／跨对话拒绝、流中断与轮数上限，并验证桌面任务卡及保存后重新打开的记录。未使用用户真实模型密钥进行付费联调。
