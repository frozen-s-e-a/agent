# JET 会计分录测试

## 概述

对序时账（日记账）进行自动化风险扫描，基于特征计算和规则匹配发现审计疑点（如跨期分录、大额整数、异常时间、借贷不平等）。

## 可用工具

| 工具 | 用途 | 何时调用 |
|------|------|---------|
| `jet_test_inspect` | 检查数据源结构 | 第一步，了解数据有什么列 |
| `jet_test_execute` | 执行分录测试 | 配置确认后调用 |

## 工作流程

```
1. inspect → 了解数据列名、类型、样本值 + 获取内置模板
2. AI 分析 → 选择适用的内置规则，生成 column_mapping，补充自定义规则
3. 展示给用户确认 → 用户可增删规则、调整参数
4. execute → 输出结果
```

## AI 决策流程

### 步骤 1：inspect 后分析

收到 inspect 结果后，AI 必须：

1. **列名匹配**：对比实际列名和内置特征需要的源列名，建立 `column_mapping`
   - 例如：实际列名"日期" → 模板需要"凭证日期"，则 `{"凭证日期": "日期"}`
   - 只映射源数据列名，特征名（如"跨月编制"）不需要映射
2. **可用性判断**：
   - 有"凭证日期"或可映射列 → 跨月编制、凭证月份、是否周末、结账后分录 等规则可用
   - 有"借方金额" → 借方余数、借方大额整万、借方负数 等规则可用
   - 有"摘要" → 摘要长度、摘要重分类、无解释分录 等规则可用
   - 无对应列的规则自动排除
3. **参数调整**：
   - "高管越权制单"的制单人名称需根据实际情况修改
   - 金额阈值（如>1000000）可根据企业规模调整

### 步骤 2：构建 execute 参数

```json
{
  "file_path": "数据源路径",
  "features": "builtin",
  "rules": ["内置规则名1", "内置规则名2", {"name": "自定义规则", "conditions": {"列名": "条件"}}],
  "column_mapping": {"模板列名": "实际列名"},
  "settings": {"company_col": null, "output_empty": false, "split_output": true},
  "output_dir": "输出目录"
}
```

**features 参数：**
- `"builtin"` → 使用全部内置特征（推荐）
- 也可传列表混合使用：`["builtin", {"name": "自定义", "tool": "数值_求余数", "source_cols": "金额", "param": "1000"}]`

**rules 参数：**
- `"builtin"` → 使用全部内置规则
- `["规则名1", "规则名2"]` → 只用指定的内置规则
- 混合：`["跨期冲回(摘要)", {"name": "自定义大额", "conditions": {"借方金额": ">5000000"}}]`

### 步骤 3：展示给用户确认

必须向用户展示：
1. 数据源概况（文件数、行数）
2. 列名映射关系
3. 选用的规则列表（标注哪些是内置、哪些是自定义）
4. 不可用的规则（缺少对应列）及原因

用户确认后才调用 execute。

## 条件语法参考

在自定义规则的 conditions 中支持以下语法：

| 语法 | 含义 | 示例 |
|------|------|------|
| `>N` / `<N` / `>=N` | 数值比较 | `>100000` |
| `=N` | 等于 | `=0` |
| `文本` | 包含 | `冲回` → 摘要含"冲回" |
| `^文本` | 以...开头 | `^6001` → 科目编码以6001开头 |
| `!文本` | 不包含 | `!调整` |
| `!^文本` | 不以...开头 | `!^1,!^2` → 不以1或2开头 |
| `#精确值` | 精确匹配 | `#坏账准备` |
| `是` / `否` | 布尔匹配 | 特征列为"是"/"否" |
| `[空]` | 空值 | `制单人: [空]` |
| `![空]` | 非空 | |
| `,` 或 `，` | 或关系 | `冲回,跨期` → 包含任一 |
| `>N,<M` | 范围 | `>22,<7` → 大于22或小于7 |

## 注意事项

1. **column_mapping 只映射源数据列名**，特征名（跨月编制、借方余数等）是计算产生的，不需要映射
2. **内置规则中的"高管越权制单"需要手动修改制单人名称**，默认值"王总,CFO"是示例
3. **金额阈值可根据企业规模调整**：小企业可用较小的阈值，大集团可用更大阈值
4. **多文件时 split_output 建议为 true**，每个主体单独输出结果文件
5. **不要读源码了解实现细节**，所有操作规则都在本文档中
