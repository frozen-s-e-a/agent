# AI 审计助手

Windows 桌面审计工作空间，当前版本 `0.1.0-internal.30`。以项目资料、正在进行的工作和处理成果组织界面，提供 63 项独立审计任务及 16 项通用资料操作。

独立业务源码位于 `src/audit-domain/`，通过客户端后台调用随包 Python 运行时执行。程序不调用原 SW 审计工具箱 EXE 或业务 PYD，打包目录不包含旧版客户端和原工具箱连接器。

## 启动

直接双击 `artifacts/AI审计助手-0.1.0-internal.30.exe`。这一个文件可独立携带，首次运行自动准备完整程序，之后复用已准备文件；无需解压、管理员权限或另装环境。项目快捷方式和根目录启动脚本也指向此单文件版本。

程序包位于 `artifacts/test/windows-x64/0.1.0-internal.30/AI助手/`，双击其中的 `AI助手.exe`。移动程序时保留整个目录；无需另装 Node、Python 或 pnpm。

根目录 `启动AI助手.cmd` 和 `AI助手桌面版.lnk` 打开当前独立程序包；`开发启动AI助手.cmd` 用于源代码开发启动。项目内 `build/runtime/node.exe` 提供构建命令所需的 Node；已有依赖时可执行 `build/runtime/node.exe scripts/dev.mjs`。

## 使用

1. 建立项目并选择资料目录，在资料工作台查看文件。
2. 选择资料后使用推荐操作，或按 `Ctrl+K` 搜索工作；下载和查询任务直接填写条件。
3. 按任务说明确认文件格式、列映射和配置。配置表可复制到项目后填写。
4. 执行后查看数据预览、提示和成果文件，使用“继续处理”衔接下一项操作。
5. 在工作记录中恢复任务，在成果文件中打开已生成结果。

AI 任务使用“运行设置”中的文本或视觉模型。注协查询、导出和在线股权穿透使用官网登录授权；本次按用户要求跳过注协在线验证。其他本地任务无需此授权。
