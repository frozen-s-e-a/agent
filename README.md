# AI 审计助手

Windows 桌面审计 Agent，当前版本 `0.1.0-internal.34`。用户在聊天中描述目标、资料范围和成果要求，Agent 读取项目或附件，调用现有独立审计程序，保存实际步骤、成果和问题。

业务源码位于 `src/audit-domain/`，提供 63 项独立审计任务及 16 项通用操作。程序不依赖原 SW 审计工具箱 EXE 或业务 PYD，旧桥接文件不进入源码仓库或程序包。

## 启动测试程序

程序目录：`artifacts/test/windows-x64/0.1.0-internal.34/AI助手/`。

双击目录中的 **启动Agent离线体验.cmd**，即可打开合成示例项目并体验聊天流程。程序自带 Node、Python 和依赖，移动时须保留整个目录。离线体验使用明确标注的模拟模型编排，文件处理由真实审计程序执行。

可输入“读取示例序时账，检查借贷是否平衡，生成差异清单”。预期输入 8 条分录、输出 1 条差异，差额 200 元。随后预览成果、新建对话提取指定列、从成果行回查原资料，测试停止继续和历史恢复。

有本机兼容模型时，双击 **AI助手.exe**，在“运行设置”配置 HTTP 本机地址与实际模型名称。当前 Agent 测试版本限制外部网络；企业模型与在线审计调用尚需明确授权和真实接口验证。

开发目录已准备依赖时，可运行 `build/runtime/node.exe scripts/offline-demo.mjs`。普通开发启动与环境准备见[源码仓库说明](docs/源码仓库说明.md)。

## 本轮范围和验证

本轮补齐 G02（工作流与节点合同）、G04（上下文与实际请求记录）、G05（持久化状态）、G06（统一工具结果与恢复）、G11（聊天界面）的本机实现。G01、G03、G07–G10 保持原有状态。

- 9 条流程覆盖全部 79 个精确能力编号。
- 45 项 Node 单元和集成测试通过；最终成果来源改动另通过 12 项 Agent 集成复验。
- 63 项独立审计程序的 83 个合成案例通过，真实外部服务未在此验证中调用。
- TypeScript 检查与 Vite 生产构建通过。
- 界面及交付程序包的实际验收记录保存在 `artifacts/agent-ui-*/Agent界面验收.json`。

文件完整性通过表示执行状态、实际文件、格式和哈希可核对。逐任务业务语义自动验收属于本轮未开展的 G01，不由模型声明完成替代。
